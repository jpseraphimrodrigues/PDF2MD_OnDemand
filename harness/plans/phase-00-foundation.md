# Phase 00 — Repository Foundation

## Objective

Establish the smallest executable and testable foundation for `PDF2MD_OnDemand`.
`uv run pdf2md` must construct `QApplication` and `MainWindow`, show a minimal
desktop window, and allow it to close. No product capability is implemented.

## Existing state

The repository contains documentation and `harness/context/README.md`, but no
`src/`, tests, Python metadata, lockfile, GUI, CI or packaging configuration.
Git is valid: `main` tracks `origin/main` and the working tree was clean before
this planning change.

## Invariants applicable

- Markdown remains sovereign; no note storage or workspace state is added.
- The GUI contains no domain or business logic.
- Domain/application code, if introduced, remains independent of PySide6.
- No premature adapters, ports, repositories, operators or generic abstractions.
- The project is local/offline, open-source and managed exclusively by `uv`.
- No Phase 0-excluded feature may be added as a placeholder.

## Minimal proposed structure

```text
.
├── .python-version
├── pyproject.toml
├── uv.lock
├── src/pdf2md_ondemand/
│   ├── __init__.py
│   └── __main__.py
├── tests/test_smoke.py
└── harness/plans/phase-00-foundation.md
```

A separate shell module may be added only if the concrete startup composition
needs it. Domain/application packages are deferred.

## Planned `pyproject.toml` essentials

```toml
[project]
name = "pdf2md-ondemand"
version = "0.1.0"
description = "Local-first Markdown workspace"
requires-python = ">=3.13,<3.14"
dependencies = ["PySide6"]

[project.scripts]
pdf2md = "pdf2md_ondemand.__main__:main"

[dependency-groups]
dev = ["pytest", "pytest-cov", "ruff", "mypy"]
```

The implementation must add the minimal build-system and tool configuration
needed for a deterministic `uv` project. No other runtime dependency is planned.

## `uv` strategy

`.python-version` fixes CPython 3.13. `uv sync` creates/updates `.venv` and
lock state; `uv.lock` is generated by `uv` and versioned. Official commands use
`uv run`; Poetry, pipenv, conda and requirements.txt are not used.

## Official commands

```text
uv sync
uv run pdf2md
uv run pytest
uv run pytest --cov=pdf2md_ondemand
uv run ruff check .
uv run ruff format --check .
uv run mypy src
```

Coverage is measured without an artificial minimum. New relevant logic requires
appropriate tests and applicable bugs require regression tests.

## Ruff, mypy and test strategy

Ruff is the only initial lint/format tool and is configured in `pyproject.toml`;
format checking uses Ruff rather than Black. Mypy targets `src`, uses Python
3.13 settings, and starts with explicit strictness compatible with the tiny
PySide6 shell. The smoke test verifies package/startup composition without
blocking on the Qt event loop. GUI behavior is manually checked only by opening
and closing the real window. Markdown, filesystem, golden, PDF and adapter
tests are deferred because those responsibilities do not yet exist.

## Minimal PySide6 shell

Startup creates `QApplication`, constructs a minimal `MainWindow`, shows it,
enters the Qt event loop, and returns its exit code. It has no file handling,
editor, preview, toolbar, workspace, database, or nonfunctional controls.

## Files expected to change

Create `.python-version`, `pyproject.toml`, `uv.lock`, the minimal package under
`src/pdf2md_ondemand/`, and `tests/test_smoke.py`. This plan is also created
now. Modify only `docs/DECISIONS.md` for the decisions recorded in this planning
step. No unrelated files are authorized.

## Implementation phases

### 00.1 — Metadata

Create project metadata, Python pin, dependency groups and tool settings.
Validate with `uv lock` and `uv sync`. Expected result: reproducible `.venv`.

### 00.2 — Shell

Create the minimal entry point and window. Validate with `uv run pdf2md` and a
manual open/close check. Expected result: a real minimal desktop application.

### 00.3 — Quality baseline

Add the smoke test and run pytest, coverage, Ruff check, Ruff format check and
mypy. Expected result: all baseline commands pass.

## Acceptance criteria

- CPython 3.13 is selected by `.python-version`.
- `requires-python` is exactly `>=3.13,<3.14`.
- `uv.lock` is generated and versioned.
- `uv run pdf2md` constructs `QApplication` and `MainWindow`.
- The minimal window opens and closes.
- No excluded feature or fake control exists.
- `uv run pytest` and coverage execution succeed.
- Ruff lint/format checks and `uv run mypy src` pass.
- No domain/application code depends on PySide6.
- No unreviewed runtime dependency is added.

## Data safety

The phase does not read or modify user Markdown, workspaces or assets. It only
adds project setup, source, tests and local environment metadata.

## Risks

### Confirmed facts

There is no implementation baseline. PySide6 is the approved runtime. CI,
packaging and all product capabilities are explicitly out of scope.

### Implementation inferences

A single package entry point and minimal shell are sufficient. Automated tests
should avoid a blocking event loop while manual validation covers real desktop
startup.

### Unresolved hypotheses

Exact window title/dimensions, headless Qt availability, and the final Ruff rule
set/mypy strictness may be adjusted during implementation without expanding scope.
