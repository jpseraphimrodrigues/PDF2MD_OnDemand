# Phase Context

This directory stores concise context records for implementation phases.

Use:

```text
phase-NN-short-name-context.md
```

Record material facts that a later Codex session would otherwise need to rediscover:

- non-obvious implementation decisions;
- dependency limitations found during a spike;
- commands/environment details that affect reproducibility;
- unresolved risks intentionally deferred;
- deviations from the original plan and why.

Do not use context files as a diary or duplicate the git log.
